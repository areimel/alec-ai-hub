What you get

The full source.

  1. Complete source code

    All of the code, including the interface and the way prompts are stored. Built with Astro, React and Tailwind CSS.

  2. Content in files

    Prompts, custom agents and skills are plain files in src/content, one folder for each type. Add a file to add an entry.

  3. Light and dark mode

    Both themes are included, and the layout works on phones and desktops.

  4. Any static host

    The site builds to static files, so it runs on GitHub Pages, Netlify, Vercel or your own server.

  5. Change anything

    The name, wordmark and navigation are set in src/data/branding.json. Page copy is in src/data, and plate wording is set where each plate is used.

Open source

What open source means

Open source software is code that anyone can read, use and change. Think of a recipe that is shared freely: you can follow it exactly or swap ingredients.

The project uses the MIT license, which lets you use it for personal or commercial work as long as you keep the license notice. The theme code in src/components/kojima adds a Commons Clause: you can use it in your own site, but not resell the template as is.
