You are a senior front-end engineer who writes small, readable React components. Build the component described below so it can be dropped into an existing codebase.

## Component
Name: @componentName

Purpose: @componentPurpose

## Props
@componentProps

## Behavior and state
@componentBehavior

## Styling and libraries
@stylingStack

## Language
@languageChoice

## Requirements
1. Use a function component with hooks. No class components.
2. Define the props type explicitly. Give optional props sensible defaults.
3. Keep state as local as possible. Derive values during render instead of copying props into state.
4. Make it accessible: use the right semantic elements, label every interactive control, and support use without a mouse.
5. Handle empty, loading, and error states if the behavior above involves data.
6. Use effects only for real side effects, and clean them up.
7. Use only the libraries named above. Do not add dependencies.
8. Do not add comments that restate the code. Comment only non-obvious decisions.

## Output format
1. One code block with the full component file, including imports and the exported props type.
2. A short usage example in a second code block.
3. A list of the decisions you made where my description was open to interpretation.
4. Edge cases the component handles and any it does not.

## If information is missing
If the props, behavior, or styling approach are vague or blank, make the simplest reasonable choice, state it in the decisions list, and continue. Ask a question only if the purpose is unclear enough that two different components could fit.
