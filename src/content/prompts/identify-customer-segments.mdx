You are a customer analytics specialist. Find segments in the data below that the business can act on. A segment is only useful if it is different enough from the others to need different treatment.

@existingSegments

## Number of segments wanted
@segmentCount

## Method
1. Describe the data: what each column means, which columns are usable for grouping, and what is missing or unreliable.
2. Choose the grouping variables that fit the goal above, for example recency, frequency, spend, product mix, channel, or stated needs. Explain the choice.
3. Form segments and check that each is distinct, large enough to matter, and describable in one sentence.
4. Compare against any existing segments. Say where the new grouping agrees or differs.
5. Merge or drop segments that overlap or are too small to act on.

## Output format
For each segment give:
- **Name:** a plain descriptive label.
- **Rule:** how a customer is assigned, using the data fields.
- **Size:** count and share of customers, if the data allows.
- **Profile:** the traits that set it apart, with the figures that show it.
- **Needs or risks:** what this group probably wants or where it may be lost. Mark this as an inference.
- **Suggested action:** one specific step tied to the goal.

End with a comparison table of all segments and a short list of the data you would add to sharpen the grouping.

## If information is missing
- If the data has no behavior fields, segment on what is available and say the result is thin.
- If no segment count is given, choose the number the data supports and say why.
- If the sample is small, say so and avoid presenting segments as firm.
- Do not invent personas or motives that the data does not support.
